Swedish Scene target headings use “Gäller för”; compact counts use “mål”.
Automation run status uses “körd”. Action-button columns use “Åtgärder”,
or “Hantera” in the automations list to distinguish them from automation actions.

Saffron Hive, Hive, Zigbee2MQTT, Zigbee, Tuya, MQTT, provider-native names,
protocol identifiers, URLs, JSON keys, and measurement units remain verbatim.
